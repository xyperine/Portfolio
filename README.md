## About ℹ️

This is my personal portfolio website, containing information about some of my most prominent projects.

The website can be viewed in either **Simple** or **Interactive** mode. Interactive mode uses real-time 3D rendering and requires a browser with GPU acceleration for good performance.

The site is built with:
- [Three.js](https://threejs.org/)
- [three.quarks](https://github.com/Alchemist0823/three.quarks)
- [Rapier](https://rapier.rs/)
- [seedrandom](https://github.com/davidbau/seedrandom)
- [Vite](https://vite.dev/)
- HTML / CSS / JavaScript

This is the first website I ever built! 😄
